桌面黑洞 — Windows x64 便携版

首次启动默认英文。右键 → Language / 语言 → 中文，即时切换；语言选择会保存。

一、打开
完整解压压缩包，双击 DesktopBlackHole.exe。无需安装 Python，不弹命令行黑框。
不要只拷贝 EXE：_internal、status-helper 等配套文件夹都要保留。
需要 Windows 10/11 x64，以及支持 OpenGL 3.3 的显卡驱动；未验证 ARM、虚拟机和所有远程桌面环境。
右键可切换画质、鼠标引力、背景扭曲、置顶/桌面置底、伴星与状态来源。
右键“开机启动（当前用户）”默认关闭。开启后仅在当前用户登录 Windows 时启动，无需管理员权限；取消即可移除。移动文件夹后请重新开关一次。系统可能延迟启动，任务管理器中的禁用可能影响此功能。
拖动移动、滚轮缩放；文件拖放仅提供视觉反馈，不移动/删除原文件。
“固定在桌面层”是置底 Tool 窗口，不是嵌入壁纸，显示桌面时可能被系统隐藏。

二、伴星
空闲保持原来的外环慢飞；处理中先升起再收近，盘上方五秒公转一圈，带弧形长尾。
由同一套光线路径处理前后遮挡，绕到明亮盘面后方时可能被遮住。
未连接或无法确认状态时保持暗光，不伪装为空闲。

三、Codex 接入
本机原来已接入的用户不需要重装；使用同一个 CODEX_HOME 即可读取现有事件。
其他电脑：右键 → 状态来源 → 安装 Codex 接入（无需 Python）。
确认后会先备份，仅合并本黑洞的八个钩子，再部署内置小信使。
随后打开 Codex CLI 的 /hooks，审查 black-hole-status 相关命令、确认信任，再重启 Codex。
信使不调用模型、仅保存限定状态字段。安装器会读取并备份配置，备份可能含私人信息，不要上传。状态灯不消耗 token。
默认每两秒检查小文件；已连接进程的工作记录只在必要时做有限尾部核实。
不包含未加载钩子、其他电脑或云端任务，不精确区分思考与逐字回复，也不判断输入框能否输入。
如需移除，在同一菜单选择“移除本黑洞的 Codex 接入”；其他钩子、备份和旧信使保留。
接入信使独立复制到 Codex 用户目录，移动便携版文件夹不影响已安装的信使。

四、DSH（可选，默认关闭）
右键 → 状态来源 → DSH 总状态（可选）。不安装、不自动启动 DSH。
首次使用：右键 → 状态来源 → DSH 接入向导。向导仅显示配置片段，不读取或修改 DSH 配置。
按 dsh-status/README.md 先备份，再合并一条持久 profile patch；保留其他插件，不要重复加载。
事件变化写一个小状态文件，每十秒健康心跳；黑洞仍每两秒检查，未变化不重读。
仅保存进程时间和忙闲计数，不保存问题、回答、工具内容或密钥。
同时选择 Codex 和 DSH：任一工作即忙；两者都确认空闲才显示空闲。
未安装 DSH、插件未加载、进程退出、心跳过期，都不会误显示空闲。
已验证一次真实 Windows web-profile 加载与忙闲计数；其他版本和完整生命周期组合仍需验证。

五、安全提示
此版未签名。Windows SmartScreen 可能提示未知发布者；杀毒软件也存在误报可能，不能保证零误报。
不要关闭防护或添加全盘排除。只使用可信来源、核对 SHA256；如检测为威胁，先停止运行并提交厂商复核。
本程序无联网更新器、无模型请求；只有明确勾选开机启动才会注册当前用户的启动项。正常首次启动默认开启桌面扭曲，在内存中处理背景，不录制或上传；关闭后停止背景采集。
设置保存在当前 Windows 用户的 Qt 设置中；源码/测试在 source.zip，依赖许可见 licenses 和 THIRD_PARTY_NOTICES.md。
启动异常时：%LOCALAPPDATA%/DesktopBlackHole/startup-error.log（仅异常信息，不是聊天记录）。
