Desktop Black Hole — Windows x64 portable edition

Extract the entire ZIP and open DesktopBlackHole.exe. No Python installation is needed. Keep _internal, status-helper and other accompanying folders beside the EXE.

Requires Windows 10/11 x64 and an OpenGL 3.3 graphics driver. Desktop-background lensing requires Windows 10 version 2004 or later. Other platforms and all GPU configurations have not been tested.

Language: English on first launch. Right-click → Language / 语言 → English or 中文. Your choice is saved. Drag to move; scroll to resize. Right-click for effects, quality and window placement. Keep below other windows is not wallpaper embedding and may be hidden by Win+D. Dropped files are never moved or deleted.

The companion is an optional local activity light. Idle: slow outer orbit. Busy: a closer orbit above the disk every five seconds, brighter breathing and a curved tail. Unconfirmed/disconnected: dim, not falsely idle.

Codex is optional. Enable the companion and Codex status source. To set up another computer, choose Status sources → Install Codex integration. The installer backs up settings and merges only this app's eight hooks. Review the black-hole-status commands in Codex /hooks before trusting them, then restart Codex. Existing connected users do not need to reinstall. The removal option preserves other hooks and backups.

DSH is separate, optional and disabled by default. Load the plugin as described in dsh-status/README.md, then enable the DSH source. The checkbox does not install or start DSH. Real-client end-to-end validation is pending; protocol tests have passed.

No model calls or tokens are used by the status light. It checks small local records every two seconds with caching; bounded Codex log-tail checks reconcile known sources when necessary. Unintegrated instances and cloud tasks are not covered. Background lensing reads the local desktop without recording it and can be disabled.

The app is unsigned. SmartScreen and antivirus warnings are possible; never disable security software just to run it. See THIRD_PARTY_NOTICES.md and licenses/ for dependency notices. source.zip contains the corresponding source. Standard quality and disabling background lensing can reduce GPU load.
